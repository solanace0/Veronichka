# Push-уведомления (работают при закрытом приложении)

Что приходит: предупреждение о скором отключении/включении, «график изменился», «появился график на завтра», экстренные отключения.

## Как это устроено
- Приложение подписывается на Web Push (сервис-воркер `sw.js`) и отправляет подписку на `/api/push`.
- Подписки хранятся в Upstash Redis. Каждые 5 минут `/api/push-cron` сверяет графики и рассылает уведомления.
- Дубли исключены: для каждой подписки хранится состояние (что уже отправлено).

## Настройка (один раз, ~10 минут)
1. **Ключи.** Локально выполните `node scripts/gen-vapid.mjs` — получите `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`, `CRON_SECRET`. В `VAPID_SUBJECT` впишите свою почту: `mailto:you@example.com`.
2. **Хранилище.** В Vercel → Storage / Marketplace добавьте **Upstash Redis** и подключите к проекту. Переменные `KV_REST_API_URL` и `KV_REST_API_TOKEN` появятся сами.
3. **Переменные окружения Vercel:** `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`, `VAPID_SUBJECT`, `CRON_SECRET`. Затем Redeploy.
4. **Таймер.** Выберите один вариант:
   - GitHub Actions: файл `.github/workflows/push-cron.yml` уже есть. В Settings → Secrets репозитория добавьте `APP_URL` (адрес сайта, без `/` в конце) и `CRON_SECRET`. Минус: GitHub иногда запаздывает на несколько минут.
   - cron-job.org (точнее, бесплатно, каждую минуту): создайте задачу `GET https://ВАШ-САЙТ/api/push-cron` с заголовком `Authorization: Bearer ВАШ_CRON_SECRET`.
5. Откройте приложение → Настройки → Сообщения → включите нужное → «Надіслати тестове сповіщення».

## Важно
- iPhone: push работает только если сайт добавлен на экран «Домой» (Поделиться → На экран «Домой»), iOS 16.4+.
- Android/ПК: работает в Chrome, Edge, Firefox после разрешения уведомлений.
- Если сервер push не настроен, приложение работает как раньше (уведомления, пока оно открыто).


## Підбір черги (автоматично, без адрес)

Адресного пошуку більше немає. Користувач відповідає максимум на 3 запитання «світло було?», а застосунок сам знаходить чергу.
- Сервер: `GET /api/schedule?all=1&city=kr` віддає графіки всіх черг зони за вчора/сьогодні/завтра (дзеркало ДТЕК/обленерго, для Дніпровщини є резерв YASNO). Застарілі файли не віддаються.
- Клієнт: черги з однаковим графіком зливаються в одну; кожне запитання вибирається так, щоб найкраще поділити решту варіантів; похибка ±15 хв враховується.
- Якщо після 3 запитань лишилось кілька схожих графіків, показуються картки з годинами відключень, і людина натискає «Це моя». Є кнопка «Ще одне запитання».
- Список черг береться з даних джерела, тому 6×2, 18×1 чи 60 груп працюють без змін у коді.
